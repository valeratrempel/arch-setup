# Arch Setup

Персональная конфигурация Arch Linux для быстрого развёртывания.

## Состав

- Niri — Wayland-композитор
- DankMaterialShell — оболочка рабочего стола
- greetd + DankGreeter — графический вход
- Наборы пакетов: base, desktop, apps, hardware и AUR

## Установка

После установки чистого Arch Linux и настройки доступа к приватному
репозиторию:

    git clone git@github.com:OWNER/REPO.git ~/arch-setup
    cd ~/arch-setup
    ./scripts/setup.sh

Перед запуском необходимо проверить совместимость пакетов,
конфигураций, файловой системы и оборудования.

## Структура

- `packages/` — списки пакетов
- `configs/home/.config/` — пользовательские настройки
- `configs/system/` — системные настройки
- `scripts/` — установка и восстановление

Секреты, токены, приватные ключи и пароли в репозитории не хранятся.
